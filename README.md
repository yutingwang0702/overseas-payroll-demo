# 海外薪酬系统（MVP 演示版）

基于《海外薪酬系统 PRD V1.0》生成的**最小可运行版本（MVP）**：内置全量 mock 数据，用于预览整体界面与主流程效果。零 npm 依赖、零构建步骤、零外部 CDN，纯原生 HTML / CSS / JavaScript 实现。

## 环境要求

- Node.js（任意版本即可，仅使用 http / fs / path 内置模块）
- 无需安装任何依赖

## 启动命令

```bash
node server.js
```

启动后访问：<http://localhost:3210>

## 目录结构

```
overseas-payroll/
├── server.js              # 零依赖 Node 静态服务器（端口 3210，UTF-8 + 常见 MIME）
├── README.md              # 本文件
└── public/
    ├── index.html         # SPA 壳：左侧固定导航 + 顶部标题栏 + 内容区（hash 路由）
    ├── css/
    │   └── style.css      # 全局样式（浅色主题，主色 #2F54EB，AI 紫 #722ED1）
    └── js/
        ├── data.js        # 全部 mock 数据（周期统一 2026-11）
        ├── pages.js       # 各页面渲染函数（每页一个渲染函数）
        └── app.js         # hash 路由 + 通用组件（表格/徽章/抽屉/弹窗/toast）
```

脚本加载顺序：`data.js → pages.js → app.js`；渲染统一由 app.js 的路由触发。

## 已实现功能范围（按 13 个页面）

### 1. 工作台（#/dashboard）
- 顶部 4 个 KPI 卡片：本月节点总数（682）/ 逾期节点（3）/ 待审账单（8）/ 待确认异动（12）
- 「11 月周期进度」：11 步流程横向步骤条（启发薪→提异动→收账单→审账单→确账单→提工资→提个税→提社保→入账→工资单→成本），标注当前整体进度（第 4 步·审账单）
- 「节点状态大盘」：25 行代表性节点数据（美国 bi-weekly、越南、德国、巴西、新加坡、日本等），支持**按国家与状态筛选**，逾期行标红、临期行标黄

### 2. 发薪日历（#/calendar）
- 「日历模板」：15 行（国家 / 主体 / 业务类型模式A/B/C / 薪制 / CutOff 编码 / 发薪日编码 / 发薪方 / 供应商 / 对接人），日期编码按 PRD 规则旁注解析（如 `105 → 次月5日`、`-3 → 月末前3天`、`-7 → 月末前7天`）
- 「本月提醒计划」：即将到期节点列表（节点 / 截止时间 / 提前提醒配置 5/3/1/0 天 / 状态）

### 3. 异动管理（#/changes）
- 20 条异动：编号 / 员工 / 国家 / 主体 / 类型（入职/离职/调薪/外派/补贴变更/银行账户变更）/ 来源（SF邮件带「可信源」徽章、手工）/ 生效日 / Retro / 六段状态机 / CutOff 风险
- 支持**按类型与状态筛选**
- **点击行弹出详情抽屉**：异动字段明细 + 状态流转时间线 + 「确认提交供应商」按钮（点击后状态真实流转、时间线追加、toast 反馈、列表同步刷新）

### 4. 外派档案（#/expat)
- 4 名外派员工卡片：双薪酬档案对照（总部档案：名义工资 / 假设税 / 税负平衡标识 vs 派驻国档案：实发工资 / 补贴 / 当地个税社保）+ 外派任务信息（派出国→派驻国、起止日期）
- 王强展示**税负平衡结算表**（名义工资−假设税 vs 派驻国实得，差额行）

### 5. 账单中心（#/reports）+ 审核详情（#/reports/:id）
- 列表页：账单编号 / 周期 / 国家 / 主体 / 供应商 / 版本 / 总额（当地币）/ 人头数 / 接收时间 / AI 预审结论 / 审核状态
- **审核详情页（核心交互）**，含 BIPO-越南、TMF-德国两份完整账单：
  - **五维比对表**：总额 / 人头 / 个税 / 社保 / 汇率折算，每行 = 基准值 / 账单值 / 差异 / 差异率 / 阈值 / 结论（通过/警告/异常）
  - **AI 预审差异清单**：每条含维度、金额、AI 归因、置信度、建议动作；合理差异标绿、疑似异常标红、低置信度标黄；疑似异常项提供「标记已处理」，其中社保异常项提供「**生成差异沟通函**」按钮（弹出预览文本，可模拟发送）
  - **底部操作条**：「提交审批」按钮——未处理完所有疑似异常项时点击出错误 toast 拦截；全部处理后提交成功、状态流转为「待审批」

### 6. 工资单中心（#/payslips）
- 顶部统计条：本月 487 张 · 自动拆分成功率 96% · 金额校验通过 484 · 异常 3
- 列表：员工 / 国家 / 主体 / 周期 / 文件名 / 拆分状态 / 校验结果（不一致标红）/ 发放状态（含退信）
- **点击行弹层查看单人工资单预览**：薪项明细（基本工资 / 电脑补贴 ¥90×当月汇率折算 / 13薪 / retro 补差 / 个税 / 社保个人 / 净额），异常单展示核对说明

### 7. 个税社保（#/compliance）
- 12 行申报跟踪：国家 / 主体 / 周期 / 税种 / 执行方（当地 Payroll / 代理 / EOR）/ 申报截止日 / 凭证状态 / 逾期预警；含 2 行临期预警（黄色高亮）

### 8. 资金支付（#/payments）
- 顶部 4 个统计卡：本月支付指令数（10）/ 待授权笔数 / 待发送笔数 / 已执行金额（折算 ¥，按当月月度汇率）
- 「支付指令」表（10 条，模式A 4 / 模式B 2 / 模式C 4）：指令编号 / 国家 / 主体 / 业务模式（A/B/C 徽章）/ 金额 + 当地币（附折算 ¥）/ 收款方（模式A/B = 当地工资账户或供应商代付账户；模式C = EOR 账单付款）/ 授权状态 / 支付状态 / 操作
- **交互**：待授权行「资金授权」按钮 → 授权状态流转 + toast；失败行红色高亮 +「重试」按钮 → 流转为已发送 + toast；统计卡随状态实时刷新
- 「EOR 账单三要素核对」（模式C 专属）：主体 / 账单服务费 / 账单实发 / 账单当地税费 / 账单合计 / 系统记录合计 / 勾稽结论（一致·绿 / 多计服务费·红）；红色行提供「**生成对账差异函**」按钮，弹出函件预览文本，可模拟发送给 EOR

### 9. 成本分析（#/cost）
- 本月海外人力总成本（折算人民币 ¥28,456,300，含环比/同比）
- 国家成本排行 Top 8（纯 CSS 横向条形图）
- 「EOR 成本三要素」示例表（体现 PRD 公式：EOR 成本 = 服务费 + 实发薪酬 + 当地税费）
- 近 6 个月月度趋势（纯 SVG 折线图）

### 10. 总账凭证（#/vouchers）
- 顶部统计条：本月凭证数（8）/ 已推送 / 已回执（显示最新 Oracle 凭证号 ORA-XXXXXX）/ 勾稽异常数
- 凭证表：凭证号（VCH-202611-XXX）/ 周期 / 国家 / 主体 / 分录笔数 / 本位币金额 ¥ / 推送状态（草稿 / 已推送 / 已回执·显示 Oracle 凭证号）/ 勾稽状态（与确认账单一致·绿 / 不一致·红，红行整行高亮）
- **交互**：
  - 点击行弹出凭证预览弹层：借贷分录明细表（借：薪酬费用-XX国 / 管理费用-社保公司 / EOR服务费；贷：应付工资 / 应交税费-个税 / 应付职工薪酬-社保 / 应付-EOR服务费等），含借贷平衡校验，底部注明折算汇率与差异科目规则
  - 「推送 Oracle」按钮：勾稽不一致的凭证点击出错误 toast「勾稽不一致，禁止推送」拦截；一致的先流转「已推送」，约 1 秒后模拟 Oracle 回执回写随机凭证号（ORA-XXXXXX）并流转「已回执」+ toast

### 11. 合同管理（#/contracts）
- 15 行合同台账：员工 / 主体（子公司/EOR 徽章）/ 合同类型 / 签署日 / 到期日 / 剩余天数 / 状态（生效中 / 90天内到期黄 / 30天内到期红 / 已过期）
- 每行「发起续签」按钮 → toast 反馈

### 12. 国别配置（#/config）
- 顶部浅蓝底说明条：「一切国别规则进配置不进代码 · 新增国家 = 新增配置包 + 日历模板，零代码发布」
- 「国别配置包」表（10 国：美国 / 德国 / 越南 / 巴西 / 新加坡 / 日本 / 菲律宾 / 印度 / 墨西哥 / 英国）：国家 / 薪制（月薪 / bi-weekly）/ 13薪（越南 / 菲律宾 / 巴西 / 墨西哥为「有」，含拆分规则）/ 最低工资 / 社保费率（公司% + 个人%）/ 个税申报频率 / 年度申报类型（W-2、IR8A、Form 16、P60 等，无则「—」）/ 冲抵上限（默认 30%，德国 20% 更严）/ 员工沟通语言 / 配置版本 + 最近生效日
- 支持**按薪制（月薪 / bi-weekly）与按 13薪（有 / 无）筛选**
- **交互**：
  - 点击行弹出配置详情抽屉：按「薪制 / 个税 / 社保 / 工资 / 冲抵 / 合同 / 汇率 / 语言 / 股权 / EOR」分组展示全部配置（含最后付薪期限规则、双边社保协定国家、RSU 税务处理等）
  - 抽屉底部「发起配置变更」→ 弹出变更表单（字段下拉自动带出旧值 / 新值 / 生效日期 / 依据说明），新值必填校验，提交后 toast「已提交薪酬主管审批」

### 13. AI 助手（#/ai）— 三个 Tab
- **法规监测**：4 条 AI 监测卡片（越南最低工资上调 6% 等，含影响面与建议动作），「生成配置变更建议」按钮出 toast
- **薪酬问答**：对话式聊天（AI 气泡紫色 #722ED1 标识），预置 2 轮历史消息（葡语员工问 13薪，AI 中文+引用回答）；脚本化回复：输入含「13薪」→ 13薪规则解释；含「工资/少发/为什么」→ 工资单差异解释（新入职比例工资 / retro / 汇率折算补贴）；含「汇率」→ 月度汇率折算口径；其他 → 转人工工单话术
- **成本预测**：未来 3 个月滚动预测表（含 13薪 季节项，越南 12 月成本翻倍等）+ 汇率敏感性 ±5%/±10% 情景区间表

## 说明

- 全部数据为演示用 mock 数据，刷新页面后状态变化（异动提交、差异处理、账单审批、资金授权、凭证推送回执等）会还原
- 界面全中文，字体统一 Microsoft YaHei；币种使用 ISO 4217 代码（USD / EUR / VND / BRL / SGD / JPY / PHP / INR / MXN / GBP）
- 日期编码规则与 PRD 5.2.2 一致：正数 N = 当月 N 日；100+N = 次月 N 日；-N = 月末前 N 天
